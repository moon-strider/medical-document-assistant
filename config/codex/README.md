# Application Codex configuration

These non-secret templates define a separate Codex profile for the medical document assistant. Its installed configuration and authentication stay in private, ignored runtime state, apart from the user's personal Codex setup. Processes still run as the same operating-system user, so this configuration does not restrict filesystem access.

Answer generation uses GPT 6 Sol High or GPT 6 Luna High. Evaluation judging uses GPT 6 Sol High.
