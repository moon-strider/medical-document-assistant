# Evidence Lab frontend

This React and TypeScript interface is the local workspace for the Medical Document Assistant. It lets a researcher browse documents, ask questions, inspect cited source passages, and review runs and evaluation results.

- **Workspace** (`/workspace`, `/workspace/:conversationId`): manage collections and documents, ask questions, and open cited PDF or TXT evidence.
- **Runs** (`/runs`): inspect saved run history, status, timing, and traces.
- **Experiments** (`/experiments`, `/experiments/:experimentId`): compare evaluated model and retrieval configurations and examine individual cases.

For local setup, see the [root README](../README.md#run-locally).
